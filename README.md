## Why the source code is not public yet

The full source code lives in a private repository owned by me (Anasentrik). It will be made public under
GPL-3.0-or-later **as soon as the mod has been approved and released on both Modrinth and CurseForge**.

I am waiting on purpose. If the source were public while the mod is still under review, anyone could build the jar
and upload it to Modrinth or CurseForge first. If their upload were approved before mine, my own mod would look like
a stolen copy, even though I am the original author and own the repository.

I know GPL-3.0 requires the source code to be available, and I will publish it. I am only waiting until the official
releases are approved on both platforms.
